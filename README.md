# rubatopress.com

Marketing / catalog site for **Rubato Press** — read-along books: prose paced to a
specific recording so you read alongside the music.

Static single-page site (`index.html`), deployed on Vercel. Type: Fraunces (display),
Newsreader (prose), Spline Sans Mono (labels). The Degas plate (*The Orchestra at the
Opera*, public domain) is embedded; the three Overture-series covers are CSS/SVG.

Imprint identity, the read-along build system, and the books themselves live in the
separate production repo **`rubato-press`** (github.com/wilsonpruitt/rubato-press).

Initial aesthetic mockup generated via claude.ai, then adopted here as the site.
